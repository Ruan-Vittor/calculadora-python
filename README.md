# 🧮 Calculadora Python

Calculadora de linha de comando (CLI) desenvolvida em Python com foco em
boas práticas de desenvolvimento, tratamento de erros e testes automatizados.

## ✨ Funcionalidades

- ➕ Soma
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão (com proteção contra divisão por zero)
- ✅ Testes automatizados com Pytest
- 🛡️ Tratamento de erros de entrada

## 🚀 Como usar

**1. Clone o repositório**

git clone https://github.com/Ruan-Vittor/calculadora-python.git
cd calculadora-python

**2. Instale as dependências**

pip install -r requirements.txt

**3. Execute a calculadora**

python main.py

**4. Rode os testes**

pytest tests/ -v

## 🛠️ Tecnologias

- Python 3
- Pytest
